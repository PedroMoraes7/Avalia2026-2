Quadro Kanban Pessoal

Construa uma ferramenta de gestão de tarefas baseada no método Kanban, estruturada nas colunas "A Fazer", "Em Execução" e "Concluído". O cliente deve ser programado em JavaScript vanilla utilizando a HTML5 Drag and Drop API nativa para permitir a movimentação fluida dos cartões entre as colunas, sem uso de bibliotecas externas. O isolamento dos dados é garantido pelo fluxo OAuth2 do Discord: ao carregar a página, o frontend busca nas Cloudflare Pages Functions apenas os cartões pertencentes àquele user_id. Cada movimentação de coluna, edição de texto ou alteração de prioridade dispara uma chamada assíncrona (PATCH/PUT) que atualiza a posição e o estado do cartão diretamente nas tabelas do Cloudflare D1.
